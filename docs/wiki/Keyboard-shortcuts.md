## Editing the key map by hand

The shortcut editor writes `%APPDATA%\LucidViewer\KeyMap.txt`. You can also edit that file in a text editor: one binding per line, the key (with `Ctrl+`, `Alt+`, `Shift+` modifiers) followed by the command name, for example

```
Ctrl+Shift+S            IDM_SAVE_SCREEN
```

Lines starting with `//` are comments. The command names are listed in `symbols.km` next to the program, and `KeyMap-README.html` there explains the syntax in detail. New commands added in later versions get their default key automatically unless your file already uses that key.
