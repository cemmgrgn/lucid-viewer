# Extras

This directory contains all the additional resources/libraries that Lucid Viewer uses or sources from.

## scripts

Misc scripts used for Lucid Viewer maintenance.

## sw_repos

Manifests for public Software Repositories

## third_party

All third-party sources and libraries which are used to build the binaries contained in the Lucid Viewer source tree.

They are NOT required to build Lucid Viewer, unless you'd like to build entirely from scratch.
